HTTP · Concept

Concept HTTP is the protocol under routes 2, 3 and 4: the client sends one request as text and the server sends one response.

one exchange with the shop
Request. A method, a path and some headers. The method GET asks to read a resource.
Response. A status code, headers and a body. The body is the page, the JSON or the file.
Stateless. Each request is answered on its own. Anything the server has to remember travels in a header such as a cookie.

Assumptions
    The server answers the whole request, headers included. Two requests for one URL can receive different responses.

The library names itself as python-requests/2.32.5. A browser sends a longer User-Agent and a dozen more headers.
headers = {'User-Agent': 'da5500w-student (your.name@example.org)'}
r = requests.get(url, headers=headers, timeout=10)
Name the scraper. A User-Agent with a project name and a contact address lets the site owner write to you before blocking you.
Set a timeout. Without one, a request to a server that never answers waits forever.

  






  
API · Concept

  
Concept
    An API is a URL that returns data for a program to read. Most return JSON, a text format with six kinds of value.

  


one product in api/products/page-1.json
{
 "sku": "SM1001",
 "name": "Sangam Medium Nappies",
 "category": "nappies",
 "price": 841,

}
JSON value → Python type after r.json()
Typed. 841 arrives as a number and true as a boolean. Nothing has to be parsed out of a sentence.
Named. Each value has a field name chosen by the people who run the server, and the names stay when the page design changes.

API · Mechanism

  
Mechanism
    Pagination: the catalogue comes in pages, and the loop follows the next field until the server sends null.

  


import time, pandas as pd
rows, url, n = [], BASE + 'api/products/page-1.json', 0
while url:
    r = requests.get(url, timeout=10)
    r.raise_for_status()                 # stop on any status that is not 2xx
    d = r.json(); n += 1
    rows += d['items']
    url = requests.compat.urljoin(url, d['next']) if d['next'] else None
    time.sleep(0.5)                      # one request every half second
api = pd.DataFrame(rows)
print(n, 'requests,', len(api), 'rows, total stated by the server:', d['total'])
print(api.dtypes.to_string())
output
7 requests, 168 rows, total stated by the server: 168
sku          object
name         object
category     object
price       float64
mrp           int64
in_stock       bool
The server ends the loop. Following next needs no page count in the code, so the loop stays correct when the catalogue grows.

HTML · Concept

  
Concept
    An HTML page is a tree of elements written as text. A scraper names the elements that hold the values it wants.

  


one product card of catalogue/page-1.html as a tree
Four things carry information: the tag name, the attributes, the text and the position of the element in the tree.
Written for a browser. The markup says how the card should look. No field is declared as a price or as a number.

HTML · Mechanism: every page

  
Mechanism continued 1
    The loop of the API section again, with a parser inside it: follow the Next link, read every card, stop when the link is absent.

  


def text(card, css):
    el = card.select_one(css)            # None when the card has no such element
    return el.get_text(strip=True) if el else None

rows, url = [], BASE + 'catalogue/page-1.html'
while url:
    r = requests.get(url, timeout=10); r.raise_for_status()
    soup = BeautifulSoup(r.text, 'html.parser')
    for c in soup.select('article.product'):
        rt = c.select_one('.rating')
        rows.append({'sku': c['data-sku'], 'name': text(c, '.name'), 'pack': text(c, '.pack'),
                     'price': text(c, '.price'), 'rating': rt['title'] if rt else None,
                     'reviews': text(c, '.count'), 'sponsored': 'sponsored' in c['class']})
    nxt = soup.select_one('a.next')
    url = requests.compat.urljoin(url, nxt['href']) if nxt else None
    time.sleep(0.5)
web = pd.DataFrame(rows)
print(len(web), 'rows,', web.sku.nunique(), 'different sku')
print(web.dtypes.to_string())
output

sku          object

text() returns None when a card lacks an element. A bare select_one(...).get_text() would stop the run at the first card without a rating.
179 rows, 168 different sku. The run raised no error and returned 11 rows too many.
